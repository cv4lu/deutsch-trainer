DEUTSCH TRAINER — Verben & Präpositionen

Вариант 1 — быстро открыть:
Открой index.html в браузере. Карточки, тест и словарь работают локально.

Вариант 2 — установить как приложение на iPhone:
Для установки PWA нужен HTTPS-хостинг (например, GitHub Pages). После публикации сайта открой его в Safari → кнопка «Поделиться» → «На экран Домой». Локальный HTML-файл не может быть установлен как полноценная PWA напрямую.

Прогресс сохраняется в браузере на этом устройстве. В комплект входят index.html, manifest.json и sw.js.
